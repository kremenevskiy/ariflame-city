# Как участвовать

Флейм-Сити строим вместе: игроки предлагают и голосуют, кто-то делает (руками или со своим ИИ), мейнтейнер проверяет и
вливает — и изменение само уезжает на сайт. Всё видно в прямом эфире на странице
[статуса города](https://city.ariflame.com/status.html). Issues и pull requests — на русском и на английском.

## Главное правило — «только лучше»

Город только растёт: правка чинит, дорабатывает, добавляет, ускоряет или делает красивее. Удалять код и файлы,
выключать или убирать механики, места, машины и режимы, замедлять игру на телефоне — нельзя, даже «ненужное»: мешает —
предложите, как починить, или сделайте настройку. Сносы находит `tools/check/only-better.cjs` (в PR — пометка
мейнтейнеру, правка с сайта отклоняется сама). Подробнее — [AGENTS.md](AGENTS.md).

## Пять способов

1. **Идея и голос.** [Обсуждения → Идеи](https://github.com/kremenevskiy/ariflame-city/discussions/categories/ideas):
   новая идея — отдельной темой, за чужие — голос ⬆. Самые нужные делаем первыми; что взяли в работу — метка «в работе»,
   что вышло — «сделано». Без GitHub — пишите в комментариях под постами в Telegram, мы переносим.
2. **Место в Минске без кода.** Любимое кафе, бульвар, двор, своё здание по фото — это данные в
   `client/places/minsk.json` ([описание формата](client/places/README.md)). Не хотите возиться с JSON — заполните
   форму [«Добавить место»](https://github.com/kremenevskiy/ariflame-city/issues/new?template=place.yml), мы соберём.
   Логотипы и названия заведений — только с согласия владельцев.
3. **Со своим ИИ без GitHub** — [city.ariflame.com/contribute.html](https://city.ariflame.com/contribute.html):
   скопируйте навык в свой ChatGPT, Claude или любой ИИ, расскажите идею (можно голосом), ИИ изучит код и отдаст архив
   с правкой — отправьте его на этой странице. Робот наложит правку на свежий `main`, проверит и откроет pull request;
   по ссылке на правку видно, что с ней, а оставите почту (необязательно) — придёт письмо, когда правку примут, выкатят
   в город или отклонят.
4. **Со своим ИИ через GitHub** — ниже: Claude Code, Codex, Copilot или Cursor на вашем форке собирают pull request.
5. **Руками** — окружение, стиль и проверки ниже.

## Со своим ИИ

Без GitHub — страница [«Сделай город лучше»](https://city.ariflame.com/contribute.html): навык для ИИ
([/dev/skill.md](https://city.ariflame.com/dev/skill.md); для Claude — архив навыка там же), весь код ссылками
([/dev/llms.txt](https://city.ariflame.com/dev/llms.txt)) и одним архивом
([/dev/flame-city-src.zip](https://city.ariflame.com/dev/flame-city-src.zip)). Свой GPT может отправлять правку сам —
действие по [/dev/openapi.json](https://city.ariflame.com/dev/openapi.json). Принимаются текстовые файлы в `client/` и
`docs/` (кроме `client/vendor/`, `client/minsk/`, `client/config.js`); удаление файлов и сносы — нет.

В корне — [AGENTS.md](AGENTS.md): как запустить, где что лежит, правила кода и содержания, как оформить PR. Его читают
Codex, Claude Code, Copilot, Cursor, Jules и другие агенты.

- **Почитать и обсудить идею в чате.** Подключите репозиторий к своему ChatGPT или Claude как коннектор (MCP):
  `https://gitmcp.io/kremenevskiy/ariflame-city` или DeepWiki (`https://mcp.deepwiki.com/mcp`, вики —
  https://deepwiki.com/kremenevskiy/ariflame-city). Бесплатно, вход не нужен.
- **Сделать pull request.** Сначала форк (кнопка Fork), потом — агент на вашем форке:
  - **Claude Code** (claude.ai/code, план Pro и выше): выберите свой форк и дайте задачу, например: *«Прочитай AGENTS.md
    и сделай: <идея и ссылка на неё>. Прогони проверки из AGENTS.md, приложи снимки и открой pull request в
    kremenevskiy/ariflame-city»*.
  - **OpenAI Codex** (ChatGPT Plus и выше): подключите GitHub, выберите форк, та же задача.
  - **Copilot / Cursor / Jules** — так же, в своём форке.
- **Без своей среды.** «Code → Codespaces» на форке — готовая среда в браузере (у GitHub Free 120 часов в месяц).
- Ответственность — на человеке: прочитайте дифф, запустите проверки и в описании PR напишите, чем пользовались
  (инструмент и модель). ИИ-PR приветствуются; один PR — одна тема, маленький дифф, снимки для видимых изменений.

## Как проходит PR

1. Проверки (CI): линтер и сборка, тесты сервера, игра в браузере — оба города и телефон, без ошибок и чужих запросов.
2. Сторож содержания смотрит дифф: политика, оскорбления, чужие адреса, опасный код, тяжёлые файлы, зависимости.
3. Бот пишет в PR отчёт: итог проверок, снимки игры и ссылку на превью — можно поиграть в вашей версии.
4. Мейнтейнер смотрит и вливает. Через пару минут изменение на сайте, а вы — в ленте «Статуса города» и среди строителей.

У новых участников проверки запускаются после одобрения мейнтейнера (защита от вредного кода). Открытых PR от одного
внешнего автора — не больше трёх одновременно.

## Окружение

```bash
npm i                                                  # eslint, esbuild, playwright (браузер: npx playwright install chromium)
python3 -m venv .venv && . .venv/bin/activate
pip install -r server/requirements.txt -r server/requirements-dev.txt
npm run dev                                            # http://localhost:8080/  (?city=minsk, ?q=low|mid|high)
cd server && FC_WORLD=fake uvicorn app:app --port 8091 --ws websockets   # онлайн; вход на localhost — ?devtok=tok-aaaa0001
```

Отладка в консоли браузера: `FC.debug` (tp, hour, rain, money, info), `FC.mis.debug`, `FC.cars.drawStats()`,
`FC.humans.stats()`.

## Стиль кода

- **Модули клиента — IIFE на `window.FC`**: `(function (global) { "use strict"; var FC = global.FC; … FC.myThing = {…}; })(window);`.
  Новый модуль — `<script>` в нужном месте `client/index.html`. Общение — через шину `FC.on/emit` и API других модулей,
  не через глобальные переменные. Без сборщика и без зависимостей в рантайме.
- **Файл — не больше 1500 строк.** Вырос — выносите часть в новый модуль (как `fmissions` → `fmissions2`).
- ES2017 без модулей ES, `var`/функции в стиле остального кода; линтер — `no-undef`, `no-unused-vars`, `no-implicit-globals`.
- Комментарии — по-русски можно и нужно: объясняйте «почему», а не «что». Грабли — в комментарий рядом и в ARCHITECTURE.md.
- Сервер — Python 3.10+, FastAPI; всё, что можно сжульничать с клиента (деньги, опыт, время), считает сервер.
- Деньги игрока — только через `FC.money`; достижения — через `FC.ach`; ресурсы миссии — через её контекст (`cleanup()`).

## Бюджеты производительности (телефон — главный)

- Средний Android на `?q=mid`: стабильно 30+ FPS в центре Минска; кадр систем на JS ≤ 4 мс.
- Вызовов отрисовки: люди ≤ 40, машины ≤ 30 + тени; без новых материалов на объект — экземпляры и общие материалы.
- Никаких выделений памяти в горячем цикле (переиспользуйте векторы), никакого `getImageData` каждый кадр.
- Новые ассеты — сжатые (WebP, meshopt GLB), догрузка после старта; стартовый трафик не растёт без причины.

## Содержание

Без настоящих брендов, логотипов и эмблем (в интерфейсе, коде и моделях); без настоящей милиции и госсимволики —
только «Патруль «Щит»»; госздания, мемориалы и храмы — не цели миссий; без политики и без крови. Новый ассет — только
со свободной лицензией и строкой в ASSETS.md (и в титрах игры, если лицензия требует). Данные OSM — только ODbL.

## Проверки перед PR

```bash
npm run lint
npm test                                    # pytest сервера
npm run dev & npm run check -- --phone      # headless: оба города и телефон без ошибок и чужих запросов
node tools/gen_tracks.cjs --check           # если трогали план Флейм-Сити (fmap.js, data/zones.js)
```

## Чеклист PR

- [ ] Одна тема на PR, описание «что и зачем», для видимых изменений — скриншот или короткое видео (телефон тоже).
- [ ] `npm run lint`, `npm test`, `npm run check` — зелёные.
- [ ] Новые файлы ≤ 1500 строк; новые модули подключены в `index.html` и описаны в ARCHITECTURE.md.
- [ ] Сервер: новая ручка — с тестом; таблицы — `CREATE … IF NOT EXISTS`, старые не ломаются.
- [ ] Нет секретов, внутренних адресов и личных данных; ассеты — со свободной лицензией и строкой в ASSETS.md.
- [ ] Правила содержания соблюдены (бренды, госсимволы, политика).
