# Как участвовать

Спасибо, что хотите помочь Флейм-Сити. Issues и pull requests принимаются на русском и на английском.

## Окружение

```bash
npm i                                                  # eslint, esbuild, playwright (браузер: npx playwright install chromium)
python3 -m venv .venv && . .venv/bin/activate
pip install -r server/requirements.txt -r server/requirements-dev.txt
npm run dev                                            # http://localhost:8080/  (?city=minsk, ?q=low|mid|high)
cd server && FC_WORLD=fake uvicorn app:app --port 8091 --ws websockets   # онлайн; вход на localhost — ?devtok=tok-aaaa0001
```

Отладка в консоли браузера: `FC.debug` (tp, hour, rain, money, info), `FC.mis.debug`, `FC.cars.drawStats()`,
`FC.humans.stats()`.

## Стиль кода

- **Модули клиента — IIFE на `window.FC`**: `(function (global) { "use strict"; var FC = global.FC; … FC.myThing = {…}; })(window);`.
  Новый модуль — `<script>` в нужном месте `client/index.html`. Общение — через шину `FC.on/emit` и API других модулей,
  не через глобальные переменные. Без сборщика и без зависимостей в рантайме.
- **Файл — не больше 1500 строк.** Вырос — выносите часть в новый модуль (как `fmissions` → `fmissions2`).
- ES2017 без модулей ES, `var`/функции в стиле остального кода; линтер — `no-undef`, `no-unused-vars`, `no-implicit-globals`.
- Комментарии — по-русски можно и нужно: объясняйте «почему», а не «что». Грабли — в комментарий рядом и в ARCHITECTURE.md.
- Сервер — Python 3.10+, FastAPI; всё, что можно сжульничать с клиента (деньги, опыт, время), считает сервер.
- Деньги игрока — только через `FC.money`; достижения — через `FC.ach`; ресурсы миссии — через её контекст (`cleanup()`).

## Бюджеты производительности (телефон — главный)

- Средний Android на `?q=mid`: стабильно 30+ FPS в центре Минска; кадр систем на JS ≤ 4 мс.
- Вызовов отрисовки: люди ≤ 40, машины ≤ 30 + тени; без новых материалов на объект — экземпляры и общие материалы.
- Никаких выделений памяти в горячем цикле (переиспользуйте векторы), никакого `getImageData` каждый кадр.
- Новые ассеты — сжатые (WebP, meshopt GLB), догрузка после старта; стартовый трафик не растёт без причины.

## Содержание

Без настоящих брендов, логотипов и эмблем (в интерфейсе, коде и моделях); без настоящей милиции и госсимволики —
только «Патруль «Щит»»; госздания, мемориалы и храмы — не цели миссий; без политики и без крови. Новый ассет — только
со свободной лицензией и строкой в ASSETS.md (и в титрах игры, если лицензия требует). Данные OSM — только ODbL.

## Проверки перед PR

```bash
npm run lint
npm test                                    # pytest сервера
npm run dev & npm run check -- --phone      # headless: оба города и телефон без ошибок и чужих запросов
node tools/gen_tracks.cjs --check           # если трогали план Флейм-Сити (fmap.js, data/zones.js)
```

## Чеклист PR

- [ ] Одна тема на PR, описание «что и зачем», для видимых изменений — скриншот или короткое видео (телефон тоже).
- [ ] `npm run lint`, `npm test`, `npm run check` — зелёные.
- [ ] Новые файлы ≤ 1500 строк; новые модули подключены в `index.html` и описаны в ARCHITECTURE.md.
- [ ] Сервер: новая ручка — с тестом; таблицы — `CREATE … IF NOT EXISTS`, старые не ломаются.
- [ ] Нет секретов, внутренних адресов и личных данных; ассеты — со свободной лицензией и строкой в ASSETS.md.
- [ ] Правила содержания соблюдены (бренды, госсимволы, политика).

Отправляя PR, вы соглашаетесь, что ваш вклад распространяется по лицензии проекта (MIT; данные OSM — ODbL 1.0).
