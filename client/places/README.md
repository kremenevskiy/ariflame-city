# Пакеты мест (FC.places, `client/fplaces.js`)

Настоящие места поверх города — данными, без правки кода. Игра грузит `places/<город>.json` (этот репозиторий: районы для
старта) и пакеты из `config.js` — `FC_CONFIG.places: ["…/minsk.json"]` (пакеты развёртывания: партнёрские места с
логотипами, названия заведений — то, что в открытый репозиторий не входит). Каждый следующий пакет дополняет предыдущие
(место с тем же `id` заменяет прежнее). Пути внутри пакета — относительно его файла.

```json
{
  "v": 1, "city": "minsk",
  "districts": [ { "id": "mayak", "name": "Маяк Минска", "about": "Бульвар, кафе", "lat": 53.93, "lon": 27.65, "h": 200, "img": "minsk/mayak.webp" } ],
  "places": [ {
    "id": "smoke", "name": "Дымок", "kind": "hookah", "lat": 53.9, "lon": 27.6, "color": "#ff7a2f", "logo": "smoke/logo.png",
    "door": { "lat": 53.9, "lon": 27.6 },
    "sign": { "type": "logo", "w": 3, "h": 1.2, "y": 3.6, "bg": "#120c18" },
    "interior": { "floors": [ { "kit": "hookah", "title": "Дымок · зал" }, { "kit": "hookah2", "title": "Дымок · второй этаж" } ],
                  "pal": { "wall": "#2a1d24", "floor": "#4a3328", "fpat": 1, "ceil": "#141016" }, "neon": "#ff4fa8", "sofa": "#6b2a3a" }
  } ],
  "biz": [ { "name": "Кофейня", "kind": "cafe", "lat": 53.9, "lon": 27.6, "bg": "#5a3a24", "fg": "#fff2de" } ]
}
```

- **districts** — экран «Где начнёшь?» при входе в город: карточка (картинка, имя, строка), точка старта и взгляд `h` (градусы).
  Без районов экрана нет; `?pick=0` или `?at=` в адресе — сразу в игру.
- **places** — большие места: логотип на карте и миникарте, вывеска у входа (`logo` — лайтбокс с картинкой, иначе буквы),
  дверь здания — в точке `door`, свой интерьер по этажам (`kit` — набор мебели `FC.furn.K`: `hookah`, `hookah2`, `club`,
  `cafe`, `store`…; `pal` — стены, пол, потолок). `kind`: hookah, bar, club, cafe, restaurant, fastfood, shop, grocery,
  pharmacy, bank, beauty, fitness, mall, service, other.
- **biz** — все заведения района: настоящее название на вывеске у ближайшей стены (вместо «ПРОДУКТЫ» у магазина OSM рядом),
  точка и имя на большой карте вблизи, имя здания у двери.

Координаты — `lat`/`lon` или `x`/`z` игры (x = (lon − 27.58)·cos 53.9°·111320, z = −(lat − 53.9)·110540).

## Своё здание места (`exterior`) — на настоящем контуре

Дом OSM под ним прячется, столкновения остаются по контуру. Два вида:

- **Без `style`** — здание-«герой» по фото (как кальянная в закрытом пакете): `poly` (контур), `h`, `floors`, `wall`, `roof`; `glass: [номера стен]`
  (стена i — от вершины i к i+1; витражи в чёрных профилях, `xbrace: true` — X-связи), `shed: {low, rise}` (скатная крыша:
  низкий край — стена `low`), `ornament: {kind: "calli", top, edges}` (ч/б «каллиграффити» по первому этажу) или
  `{color, density}` (мазки кистью), `bands: [{edges, y0, y1}]` (полосы орнамента ромбами), `canopy: {edges, h, depth, color}`,
  `logo: {edge, t, y, d}` (круглый световой логотип), `porthole: {edge, t, y, r}` (круглое окно, вечером — с логотипом),
  `annex: {edge, depth, h}` (остеклённая терраса с диванами, канатами, огоньками), `fence: {edge, dist}` (ограда у бордюра),
  `upperWindows: false`, `groundEdges: [стены с витринами]`.
- **`style`** — дом района: `bands` (стекло с поясами), `stripes` (белое с песочными полосами и голубыми лоджиями),
  `grid` (рамы с цветной вставкой: `colors.accent`, `accent2`), `brick`, `render`, `pastel`, `ribs` (металлические рёбра);
  `colors {...}`, `bay` (пролёт, м), `podium: {h, kind: "shops"|"arcade", color}` (витрины или белая аркада), `steps: [[этаж,
  отступ]]` (уступы), `pitch: {h, d, color}` (скатная крыша-мансарда), `crown: {h, color}`, `towers: [{x, z, r, h, dome}]`
  (башенка с куполом), `arch: {w, h}` (сквозной проём), `vault: {x0, x1, c, r, spring, led}` (мост с полуциркульным сводом),
  `far` (с какого расстояния строить, м).

## Улицы и бульвары (`streets`)

`{id, points: [[x, z]…], width, paving: {a, b, tile} | false, rows: [{off, every, start, prop}], items: [{prop, x, z, …}]}` —
мощение плитами, ряды `topiary` (деревья-шары), `tree`, `bench`, `lamp`, `planter`, `bollard`; `items`: `fountain {r, h}`,
`globe {r}`, `statue`, `lens {len, w, rot}` (газон-«линза» с кустами).
