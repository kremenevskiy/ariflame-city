# Флейм-Сити — устройство игры

Как устроено внутри: модули клиента, контракты `FC.*`, сервер, данные Минска, ассеты и лицензии, грабли.
Запуск — [README](../README.md), сервер — [server/README.md](../server/README.md), выкладка — [DEPLOY.md](DEPLOY.md),
вход — [AUTH.md](AUTH.md).

## Клиент

Чистый браузерный JavaScript без сборщика: ~55 модулей-IIFE в `client/`, каждый вешает свой API на `window.FC`. Порядок
загрузки — `client/index.html`. Модули говорят друг с другом через шину (`FC.on/emit`) и объекты-API (`FC.map`,
`FC.cars`, …), а не через общие переменные — так каждый можно править отдельно. Движок — своя урезанная сборка three.js
r160 (`client/vendor/three-r160.js`, собирает `tools/world-three.cjs`: нет `LineSegments`, `ShaderChunk`, имени
`AgXToneMapping` — константа 6).

| модуль | что |
|---|---|
| `config.js` | настройки развёртывания `window.FC_CONFIG` (сервер, вход, ссылки, музыка) — файл заменяют при выкладке |
| `fplaces` | места данными (`FC.places`, пакеты `client/places/`): районы для старта, большие места с логотипом, своим зданием и интерьером, вывески всех заведений, свои здания районов по стилям, бульвары; формат — `client/places/README.md`. В Минске здесь же рисуется штаб «Башня Флейм» — с 23.11.2026 он стоит на строящемся участке Западного коммерческого квартала «Минск-Мира» (`fmapx` переносит запись), а у «Маяка Минска», где его ставил конвертер, — пусто, как в жизни |
| `fcrowd` | «Рядом с игроками» (`FC.crowd`): карточка «Рядом с игроками · N онлайн» на «Где начнёшь?» — только когда в городе кто-то есть, и «👥 К игрокам» на большой карте (через `FC.hud.teleport`). Место — тротуар или площадь в 15–40 м от центра самой людной кучки (сервер `GET /g/crowd`: клетка 20 м, как в `who`, без номеров и ников), не в доме, не в воде, не на проезжей части; в Минске дома и вода приходят с кусками — место проверяется ещё раз, когда они построены |
| `flive` | жизнь мест: люди гуляют вдоль бульваров и площадей из пакетов мест, мотоциклы и машины у краёв — по уровню района |
| `fmetro` | метро Минска под землёй: три линии в настоящем порядке, островные платформы, синие поезда по расписанию, поездка в вагоне с белорусскими объявлениями, пересадки, часы-интервалы; пути и тоннели проходимы, поезд сбивает. Под землёй подменяет `FC.inside` |
| `floader` | экран загрузки `window.FCL` — первый скрипт страницы: выбор города (`window.FC_CITY`), ключ-арт `client/loader/` (вертикальный `-p` на телефоне, сцена меняется от захода к заходу), дорожный указатель «км до города» по ходу загрузки, советы. У Минска экран свой: указатель как на белорусских дорогах («Мінск / Minsk»), сверху «Минск 1:1», пять узнаваемых мест города. Пока он на экране, цикл игры не считает и не рисует; `fmain` ждёт кадра с картинкой (`FCL.afterPaint`, ≤ 1,2 с), потом строит город и убирает заставку (`FCL.done`). Разработка: `?loader=hold` — заставка не уходит, `?art=<сцена>` — нужная картинка |
| `fcore` | ядро: сид-рандом, шина, системы, сохранение (`localStorage` по rid), деньги — одна дверь `FC.money`, часы; `FC.cfg`, адрес сервера `FC.gs()/gsWs()/gfetch()`, талисман `FC.MASCOT` |
| `finput` | клавиатура, мышь, тач (непассивные касания, плавающий джойстик) |
| `fmap` / `fmapx` | план Флейм-Сити (сетка ±1200 м) / тот же `FC.map` для Минска из OSM (ломаные рёбра, одностороннее, дома под углом) |

| `fair` | вертолёты, самолёты, парашют, аэродром |

Данные клиента: `data/zones.js` (здания-зоны — места, где работают ИИ-агенты города), `tracks.json` (трассы — тот же
файл читает сервер), `ach-missions.json` (реестр достижений миссий), `minsk/` (Минск 1:1), `people/`, `cars/`, `tex/`.

### Контракты

- **Шина**: `FC.on(событие, fn) → off`, `FC.emit(событие, данные)`. Примеры: `me` (кто играет), `inside:enter|exit`,
  `weapon:equip|fire|reload|swing|throw|hit`, `mission:start|pass|fail|abort`, `ach:unlock`, `photo:pose`.
- **Системы**: `FC.addSystem({name, order, init, update(dt)})` — цикл `fmain` зовёт по `order`.
- **Деньги**: только `FC.money(delta, причина)` — `false`, если не хватает; сервер сверяет прирост «заработано».
- **Достижения**: `FC.ach.define({id, name, desc, icon, rarity: common|rare|epic|legend, hidden, need})`,
  `FC.ach.unlock(id)`, `FC.ach.add(id, d)`; id с префиксом модуля (`sec_…`, `mis_…`).
- **Миссии**: всё, что миссия создаёт (машины, люди, метки, таймеры, меши, DOM), регистрируется в контексте
  (`c.car/heli/npc/mark/interact/on/later/add/el/ramp`), одна `cleanup()` снимает всё; проверка — `FC.mis.debug.leaks()`.
- **Телефон**: `FC.hud.addApp({id, icon, name, color, order, render(body, ctl)})`.
- **Сервер**: `FC.gfetch(path, opt)` — запрос к игровому серверу (при выключенном онлайне — сразу отказ).
- **Ник**: `FC.nick.name()`, `FC.nick.open()` — лист смены ника; событие `nick`. Свои строки в паузу и «Настройки» — `pause:open` (карточка паузы), `phone:settings` (список настроек).
- **Вход**: `FC.me = {rid, guest, name, label, home, …}`; `FC.net.token` — токен вошедшего; `FC.net.loginHint()`,
  `FC.net.openLogin()` — подсказка и кнопка входа для текущего провайдера.
- **Виды (необязательно)**: `window.FC_SPECIES = {META, CRE, LINES, atlas, img(code)}` — набор «существ» для фигурок и
  спрайтов. По умолчанию не подключён: все персонажи — люди (`fhumans`), служебные фигуры рисуются холстом, талисман —
  `FC.MASCOT.img`.
- **Лента жителей (необязательно)**: `FC.people.setCitizens(list)` рассаживает «живых агентов» внешнего сервиса по
  зданиям-зонам (`flife`). В этой сборке источник не подключён.

### Качество и производительность

`?q=low|mid|high` (телефон — mid, компьютер — high, при FPS < 32 в первые секунды — ступень вниз). `?fps` — счётчик кадров в углу (к/с, худший кадр, качество, масштаб рендера). Бюджеты: люди — 11–28
вызовов отрисовки (`FC.humans.stats()`), машины — один материал и InstancedMesh на тип (`FC.cars.drawStats()`), фигурки
строятся по одной за кадр. Внутри здания не рисуются солнечные тени и дальний город. Улицы Минска наполняются пачками.

### Грабли

- Значение на здание (вид, сид), идущее атрибутом-varying, интерполируется с погрешностью — перед хэшем `floor(x + 0.5)`.
- NaN в одном пикселе свечение размазывает в чёрный прямоугольник — только `pow(max(x, 0.0), k)` и `smoothstep` с a < b.
- Цвет вершин three считает линейным — sRGB-HEX переводить (`linOf`), иначе всё выбелено.
- Плоскость-земля 60 км перекрывала дороги вдоль улицы (точность глубины) — теперь 8 км за камерой с polygonOffset.
- `getImageData` без `willReadFrequently` (контур фигурки) — 60% CPU; читаем один раз и кэшируем.
- Отражения — не `RoomEnvironment` (одинаково днём и ночью), а PMREM из шара-неба.

## Сервер

`server/` — FastAPI + WebSocket, своя SQLite; положения игроков — только в памяти, рассылка ближних 10 раз в секунду
(радиус 350 м, внутри здания — только то же здание). Сервер — арбитр: опыт, деньги от бизнеса, время гонки, итоги недели
он считает сам, клиент сообщает только, что сделал. Ручки, схема, честность, личность — [server/README.md](../server/README.md).

## Минск 1:1

Второй город — настоящий Минск из OpenStreetMap (© участники OpenStreetMap, ODbL 1.0). Выбор — экран загрузки,
`?city=minsk`, настройки телефона (`localStorage` `fc.city`); `FC.city`, тексты — `FC.cityName/cityTo/cityIn/cityOf`.

- **Данные**: `tools/minsk-osm.py` (срез `.osm.pbf` → pyosmium) → `client/minsk/`: `meta.js` (граф улиц, важные дома,
  районы — грузится синхронно до модулей), `map.json` (подложка карты), `s_<x>_<z>.json` (суперкуски 1 км: контуры, дороги,
  вода, зелень, деревья, фонари), `addr.json` (адреса для «Найди свой дом»). Формат 2: приращения в дециметрах.
- **Семейства домов** — классификатор `classify` в `minsk-osm.py`: хрущёвки, панельки, «свечки», сталинки, новые КПД,
  монолит, стекло, историческое ядро, частные дома, школы, промзона… Коды 20–37 → шейдер фасада `fgfx` (окна под стену и
  этажность, лоджии, балконы, витрины, «комната» за стеклом). Атлас `tex/facades.webp` — для части видов.
- **Сохранение**: один файл; место, дома, мебель и районы банд — по городам (`cities.minsk`), деньги, гараж и сюжет — общие.
- **Онлайн**: `hi.city` — игроки видят только свой город (граница — `CITY_LIM` в `server/app.py`).

### Право и содержание (Беларусь-безопасно)

- Реальной милиции, ОМОНа, госсимволов нет — розыск ведёт вымышленный **«Патруль «Щит»»**; госздания — фон без имён,
  мемориалы — тихие зоны (целями миссий и покупок не бывают: `M.gov`, `M.quiet`, список `BAD` в `fphoto.js`), храмы не
  продаются; барельефов и гербов на ориентирах нет (в Беларуси нет свободы панорамы).
- Бренды — нейтральные имена (вывески категорий «ПРОДУКТЫ», «АПТЕКА»); машины — только свои марки-пародии без настоящих
  названий, эмблем и решёток — ни в интерфейсе, ни в коде, ни в моделях.
- Без политики: фильтр чата клана режет политику, ссылки, телефоны и мат (`crews.clean`). Крови нет.
- ODbL: данные кусков — производная база; она распространяется под ODbL 1.0 и отдаётся по запросу; подпись — на заставке,
  в карте и на снимках фоторежима.

## Ассеты

- **Люди** (`client/people/`) — Microsoft Rocketbox (MIT) + анимации Quaternius UAL1 (CC0); конвейер `tools/fc-humans/`
  (`run.sh`: скачать → Blender 5.x `build.py` → `tex.py` атлас и маска одежды → `pack.cjs` meshopt). Титры — `people/CREDITS.md`.
- **Машины** (`client/cars/`) — свой параметрический генератор (`tools/lib/fc-cargen.cjs`, рецепты `fc-carbodies.cjs`,
  сборка `npm run cars` → `cars-<хэш>.glb` и имя в `fcarsgl.js`). В вершинах `COLOR_0.a` — вид поверхности (краска, стекло,
  хром, фары…).
- **Фасады** (`client/tex/facades.webp`) — сгенерированы (см. `tex/CREDITS.md`), лицензия проекта.
- **Талисман** Уголёк (`client/brand/`) — свой рисунок, SVG → PNG (`node tools/brand-png.cjs`).
- **Музыка** не входит: радио играет процедурный синтез; свои треки — `config.js` `music`.

Полный список лицензий — [ASSETS.md](../ASSETS.md).

## Как добавить

- **Здание-зону** — строка в `client/data/zones.js` (в конец: порядок влияет на раскладку участков), задачи смены — в
  `fgames.js` (`REQ[key]`), при желании — свой интерьер в `ffurn.js` (`ZONE_KIT[kind]`). После правки плана —
  `node tools/gen_tracks.cjs --check`.
- **Миссию** — запись в `fmissions2.js` по образцу (интро, пороги медалей, `start(c)` с ресурсами через контекст), достижения —
  `ach-missions.json`. Проверка: `FC.mis.debug.begin(id)`, потом `FC.mis.debug.leaks()` — после уборки все нули.
- **Машину** — тип в `fcarlist.js` (класс, марка-пародия, характеристики), рецепт кузова — `tools/lib/fc-carbodies.cjs`,
  затем `npm run cars`.
- **Город** — свой `meta.js`/куски в формате `client/minsk/` (конвертер `tools/minsk-osm.py` — образец) и переключатель в
  `index.html`/`fcore.js` (`FC_CITY`); тексты города — `FC.cityName…`; граница — `CITY_LIM` на сервере.
- **Вход** через свой сервис — [AUTH.md](AUTH.md).

## Проверка

`npm run lint` (no-undef, no-unused-vars), `npm test` (pytest сервера), `npm run check` (headless: оба города стартуют без
ошибок консоли и без запросов за пределы своего адреса; `--phone` — телефон, `--shots docs/img` — снимки). В консоли:
`FC.debug` (tp, hour, rain, money, info), `FC.mis.start("tour")`, `FC.secrets.state()`.
